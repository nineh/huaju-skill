格式不用手调，
一键排成公文和法律文书

调标点、字体、段落和页码最费时间，还容易漏。这个技能按 GB/T 9704 公文格式标准自动处理 Word 文档，网页和 AI 助手里都能用。

分享人

韩宇

适用工具

华炬在线版、通用 Agent

文件格式

.docx

可见范围

公开

能做什么

  • 一键智能处理：统一标点、字体、段落、页边距和页码。
  • 格式诊断：只检查问题，不改原文档。
  • 四种预设：公文、论文、法律文书、自定义。
  • 自定义排版（在线版）：自己设定页边距、各级文字、行距和页码，保存在浏览器里或导出 JSON 复用。
  • 参照样板排版（韩宇新增）：上传一份排好的文件，照着它的格式排。
  • 修订标记：改动以 Word 修订记录呈现，方便审阅。
  • 文本转文档：把纯文本或 Markdown 直接生成规范的 Word 文件。

用法一：打开网页直接用

打开华炬在线版，拖入 .docx 文件，选处理方式，下载排好的新文件。文件只在你的浏览器里处理，不上传服务器。

韩宇新增参照样板排版：再上传一份排好的样板（比如所里的律师函模板），就能照着它的格式排。

用法二：装进 AI 助手

  1. 下载右侧的技能包并解压。
  2. 把文件夹放进你所用 AI 助手的技能目录（Claude、WorkBuddy、OpenCode 等）。
  3. 对 AI 说：「按公文格式排版这份文件」或「检查这份文书的格式问题」。

会用命令行的，也可以直接运行：

python scripts/process.py smart 输入.docx 输出.docx --preset official

注意

  • 优先使用 .docx。.doc 和 .wps 需要在 Windows 上先转换。
  • 处理前请备份重要文件。
  • 排版结果仍需律师复核。
